# 🫧 Bubble Game

A fast-paced number-matching browser game with a stylish animated landing page.

🔗 **[Play it live here](https://aditya90569056.github.io/bubble-game/)**

---

## 🎮 How to Play

1. A **target number** is shown at the top of the screen.
2. Click the **bubble** that matches the target number.
3. Each correct click earns **10 points** and refreshes the bubble grid.
4. You have **60 seconds** — score as high as you can!

---

## ✨ Features

- 🕹️ **Simple & Addictive Gameplay** — Click the right bubble before time runs out
- ⏱️ **60-Second Timer** — Race against the clock
- 🔊 **Sound Effects** — Satisfying audio feedback on each correct hit
- 🎨 **Animated Landing Page** — Smooth GSAP + Locomotive Scroll entrance animation
- 📱 **Responsive Design** — Works on desktop, tablet, and mobile

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML / CSS / JavaScript | Core structure, styling, and game logic |
| [GSAP](https://gsap.com/) | Landing page animations & transitions |
| [Locomotive Scroll](https://locomotivemtl.github.io/locomotive-scroll/) | Smooth scrolling on the landing page |
| [RemixIcon](https://remixicon.com/) | Navigation icons |
